The part-time everything era

2018–2021 · Before software

  • May – Nov 2021
    PAVÉ Limited
    Sales merchandiser, part-time — merchandising for a confectionery heavyweight. The takeaway: if you've ever seen a chocolate shelf look unreasonably good, someone did that at 5am — and never once got thanked for it.
  • Feb – Jul 2021
    Tech Colab
    Entry-level developer, part-time — the first actual code for money. Worked collaboratively on two projects: a Java mobile/desktop application, and a full-stack web application with Python and Django.
  • Sep 2020 – Jun 2021
    Beercycle
    Christchurch beercycle driver — full-time, pedal-powered logistics, and the most fun job on this entire page.
  • Apr 2019 – Sep 2020
    Kraft Heinz
    Merchandiser — sauce and condiments edition. Same shelves, different bottles. The takeaway: retail is an operations game played at 6am, and everyone pretending otherwise has never set foot in the back room.
  • Jul 2018 – Jan 2019
    Fonterra
    Merchandising as a next-gen milk man — servicing store routes, facing product, learning how a category actually runs on razor margins. The takeaway: the milk round never died, it just swapped the float for a merchandising app.

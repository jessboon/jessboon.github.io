Hit the ground running within McKinsey as a junior engineer with a leading digital fitness media player.

**Role:** Software Engineer · 2022 H2

**Stack:** AWS, Lambda, DynamoDB, Redis, Node, Python

**Goal:** Build a new stack, interface, and approach to affiliate/code-based signups — ensuring we accept and manage the affiliate market through branding, tailoring, correlation of signups to affiliates, and storing respective metadata around each interaction.

<p><strong>Impact:</strong> <span class="impact">Decreased churn rate by 6% across member signups.</span></p>

## Responsibilities

1. DynamoDB data model definition to store:
   1. Affiliates
   2. Affiliate signups
   3. Consumer signup to affiliate mapping
2. Integration with headless CMSs for branding and tailored UX based on affiliate.
3. Lambda serverless API components to serve the frontend affiliate interface.
4. Integration with CMS and other internal systems.
5. Enhanced observability via aggregated logging mechanisms.
6. CI/CD via GitHub Actions and deployment in Azure.

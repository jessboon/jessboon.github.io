Lead software engineer on a platform for large-dataset theme extraction using a variety of data science and ML techniques.

**Role:** Lead Software Engineer · 2024 H1

**Stack:** Python, AWS ECS, AWS RDS PostgreSQL, Redis, Celery, OpenAI, React, Node.js, TypeScript

**Goal:** Develop a platform for unstructured data analysis to understand themes, their prevalence and references.

<p><strong>Impact:</strong> <span class="impact">Reduced the time to analyse customer reviews by 35%.</span></p>

## Responsibilities

1. Lead a team of 2 software engineers across frontend and backend.
2. Liaise with business and leadership on direction, design, and approach.
3. Design and architect:
   1. Data architecture to store analysis result sets with lineage and auditability.
   2. Large input file handling through direct browser-to-S3 upload paths and dataframe streaming for processing.
   3. Async workflow architecture to handle analysis involving dynamic runtimes from 30 seconds to 10 minutes — handling retries, failures, and other edge cases.
4. Engineering across the stack to implement feature requests and optimise workflow execution.
5. CI/CD via GitHub Actions, centralised monitoring and maintenance.

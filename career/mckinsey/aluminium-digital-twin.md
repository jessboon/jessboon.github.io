Long-term engagement with a large aluminium producer in the Emirates.

**Role:** Software Engineer · 2023 H1

**Stack:** C#, ASP.NET, Simio, SQL, Redis, Blob Storage

**Goal:** Deployment of a large Simio-based digital twin optimising supply-chain constraints across the value chain.

<p><strong>Impact:</strong> <span class="impact">Enabled supply-chain scenarios that previously took days to execute against live constraints in hours.</span></p>

## Responsibilities

1. Architect and provision infrastructure to host a dynamic digital twin, enabling VM orchestration to programmatically access SIMIO.
2. Design and implement the simulation results data model.
3. Implement an async approach for simulation execution, results retrieval, and interface notifications.
4. Implement observability mechanisms.
5. CI/CD via Azure Git and deployment in Azure.
